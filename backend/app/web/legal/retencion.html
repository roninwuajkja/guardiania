Ciclo de vida

Retención, exportación y eliminación

Conservamos solo lo necesario para prestar el servicio, proteger la cuenta y cumplir obligaciones. La retención se ejecuta automáticamente.

1. Exportación

Desde Privacidad y datos → Descargar mis datos obtienes un JSON con perfil, consentimientos, dispositivos, vinculaciones, alertas, señales y auditoría reciente. La descarga requiere sesión autenticada y queda auditada.

2. Eliminación de cuenta

La eliminación exige contraseña y la frase ELIMINAR MI CUENTA. Revoca sesiones y dispositivos, borra alertas, capturas y consentimientos, y anonimiza el perfil. Se conserva una constancia mínima de la eliminación sin identificar a la persona, para demostrar cumplimiento.

3. Excepciones legales

Podemos conservar información específica si una ley, una orden judicial o una investigación de seguridad lo exige. En ese caso limitamos el acceso, documentamos la base y eliminamos en cuanto cesa la obligación.

4. Copias de seguridad

Las copias deben cifrarse y tener retención máxima de 35 días. Una eliminación se propaga a las copias en el siguiente ciclo; no se restauran datos eliminados salvo para recuperar el servicio, con nuevo plazo acotado.

5. Verificación

El trabajo de retención registra conteos agregados, no identificadores. Los ensayos de restauración y borrado se documentan en docs/compliance/retencion.md.
